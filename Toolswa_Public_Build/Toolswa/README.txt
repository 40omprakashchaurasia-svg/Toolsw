TOOLSWa UPDATED BUILD

Included:
- Purple and white responsive theme
- Working persistent dark/light mode
- Single-page tool workspace (tools open in the same browser tab)
- Search and category filters for all included tools
- Three-dot menu: About, Contact Us, Privacy Policy
- Drag-and-drop upload for every tool (Word Counter accepts .txt files)
- PDF Merge, PDF Split, PDF re-save/optimize, Image Resizer, Word Counter

Important limitations:
- This ZIP contains the five tools present in the original starter ZIP. It does not invent additional tools.
- PDF features require an internet connection to load pdf-lib from unpkg CDN.
- PDF Compressor re-saves the PDF using object streams. It cannot guarantee a smaller file and does not recompress embedded images.
- Files are processed in the browser; large files may use significant device memory.
- Replace hello@toolswa.com if needed and review the privacy policy before publishing.

Deploy:
1. Extract this ZIP.
2. Upload the contents of the Toolswa folder to the root of your GitHub repository (or deploy the folder with Netlify).
3. Ensure index.html, style.css, app.js and README.txt are at the deployed site root.
4. Test each tool with sample files after deployment.
